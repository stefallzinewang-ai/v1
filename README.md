# 主线雷达 · Mainline Alpha Radar

> 一个**自上而下、市场状态感知**的 A 股主题投资研究系统。
> 它不下单、不做交易执行，只回答一个问题：
> **「在当前的宏观 / 政策 / 行业 / 市场状态下，顺着产业主线往下拆，哪一两家公司值得买入？」**

---

## 这是什么

传统选股要么纯看技术面，要么纯看财务。本系统的核心假设是：

> **一只股票会不会涨，取决于「它所处的位置」与「当前的市场状态」是否匹配。**

所以我们用过去约 **15 年**的历史数据，去归纳「**在不同市场状态下，会上涨的股票具有哪些共性**」——
这些共性同时包含四个层次的关联信息：

| 层次 | 关心的问题 | 例子 |
|------|-----------|------|
| 🌏 宏观 / 政策 | 国家经济处于什么阶段？政策在扶持谁？ | 货币宽松、产业政策倾斜 AI |
| 🏭 行业景气 | 哪些行业正在景气上行？ | 人工智能行业爆发 |
| 🔗 产业链主线 | 顺着主线往下，瓶颈环节在哪？ | AI → 数据传输是核心 → 光模块是瓶颈 |
| 🏢 公司基本面 | 这个环节里，哪家公司最能兑现业绩？ | 某光模块龙头的各季度指标 |

把当前的真实数据套进归纳出来的规律，最终输出一份**带理由、可追溯**的候选清单（通常 1~2 家）。

## 一个完整的例子（系统内置示例）

```
当前市场状态：成长占优 / 景气驱动
        │
宏观+政策：流动性中性偏松，政策明确支持人工智能 ──┐
        │                                        ├─→ 选定主题：人工智能
行业景气：AI 算力需求爆发，数据中心高速扩张 ───────┘
        │
产业链主线：AI 训练/推理 → 海量数据传输是核心 → 光模块是传输瓶颈
        │（瓶颈环节 = 光模块，关键变量 = 传输速率 800G/1.6T、产能、良率）
        │
公司层：在光模块环节里，按「营收增速 / 毛利率 / 产能爬坡 / 估值分位」打分
        │
输出：候选公司 1~2 家 + 每一条理由的数据出处
```

> 对应的配置文件见 [`config/themes/ai_optical_module.yaml`](config/themes/ai_optical_module.yaml)。

## 系统架构（八层）

```
┌─────────────────────────────────────────────────────────────┐
│  8. 报告层 report     研究报告 / 候选清单 / 逻辑链可追溯        │
├─────────────────────────────────────────────────────────────┤
│  7. 回测层 backtest   用 15 年历史验证「规律」是否真的有效      │
├─────────────────────────────────────────────────────────────┤
│  6. 选股层 selection  综合打分 → 输出 1~2 家候选              │
├──────────────┬──────────────┬───────────────────────────────┤
│ 3.规律挖掘    │ 4.主线映射    │ 5.公司基本面                   │
│   mining     │   theme      │   fundamental                 │
│ 不同状态下的  │ 产业链知识库  │ 各季度财务指标打分             │
│ 上涨共性/因子 │ 主题→瓶颈环节 │                               │
├──────────────┴──────────────┴───────────────────────────────┤
│  2. 市场状态识别 regime   牛/熊/震荡、成长/价值、风险偏好       │
├─────────────────────────────────────────────────────────────┤
│  1. 数据层 data    行情 / 财务 / 宏观 / 行业 / 政策（关联数据） │
└─────────────────────────────────────────────────────────────┘
```

详细设计见 [`docs/architecture.md`](docs/architecture.md)。

## 快速开始（当前为骨架阶段）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 复制配置
cp config/settings.example.yaml config/settings.yaml

# 3. 采集数据（需在可访问东方财富的机器上运行）
python -m alpharadar.cli sync ai_optical_module

# 4. 端到端运行：市场状态 → 主线激活 → 选股 → 研究报告
python -m alpharadar.cli run ai_optical_module --save

# 其它：分步查看
python -m alpharadar.cli regime                 # 当前市场状态
python -m alpharadar.cli theme ai_optical_module  # 主线收敛链
python -m alpharadar.cli score ai_optical_module  # 候选池基本面打分
```

> ⚠️ **进度**：八层架构已端到端打通（数据/市场状态/主线/因子/基本面/选股/报告），
> 可生成完整研究报告；规律挖掘(阶段5)、回测、宏观/估值/景气因子按
> [`docs/roadmap.md`](docs/roadmap.md) 持续填充。
> 数据采集需在可访问数据源的机器上运行（云环境白名单代理会拦截，返回 403）。

## 数据源

A 股数据默认采用 [**AKShare**](https://akshare.akfamily.xyz/)（免费、覆盖行情/财务/宏观/行业）。
可选接入 Tushare、baostock 作为补充。详见 [`docs/data-model.md`](docs/data-model.md)。
