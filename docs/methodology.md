# 方法论：市场状态 · 因子 · 规律挖掘

> 对应第 2 层 `regime`、第 3 层 `mining`、第 5 层 `fundamental`。
> 本文回答系统的「智力核心」：怎么定义市场状态？怎么从 15 年历史挖出「会涨的共性」？

## 1. 市场状态 Regime（第 2 层）

「同样的因子，在不同市场状态下有效性天差地别」——这是本系统的立身之本。
我们用**多维标签**而非单一牛熊来刻画状态：

| 维度 | 取值 | 判断依据（示例） |
|------|------|------------------|
| `trend` 趋势 | bull / bear / range | 宽基指数相对 200 日均线位置、斜率、新高新低 |
| `style` 风格 | growth / value / balanced | 成长指数 vs 价值指数相对强弱（如创业板/上证 50 比值） |
| `risk_appetite` 风险偏好 | high / neutral / low | 小盘/大盘比值、波动率、两融余额变化 |
| `liquidity` 流动性 | easing / neutral / tightening | M2/社融同比、利率（SHIBOR）、央行操作 |

**实现思路**：每个维度先用规则（阈值）打标签，作为可解释的 baseline；
后续可升级为隐马尔可夫/聚类做状态划分。状态切换需加**平滑/确认**，避免频繁抖动。

> 输出数据结构见 `src/alpharadar/regime/detector.py::RegimeState`。

## 2. 因子库 Factors（第 3、5 层共用）

因子 = 把原始数据加工成「可比较的横截面特征」。分五大类：

| 类别 | 代表因子 | 数据来源 | 直觉 |
|------|----------|----------|------|
| **景气 Prosperity** | 行业出货增速、订单、产能利用率、价格趋势 | 行业 | 主线是否真的在爆发 |
| **成长 Growth** | 营收 YoY、净利 YoY、增速的边际变化 | 财务 | 业绩能不能兑现 |
| **质量 Quality** | ROE、毛利率、现金流/利润、资产负债率 | 财务 | 赚的是不是真钱 |
| **动量 Momentum** | 1/3/6 月收益、相对行业强弱、资金流 | 行情 | 市场是否已在认可 |
| **估值 Valuation** | PE/PB/PS 的历史分位、PEG | 行情+财务 | 是否已经透支 |

每个因子统一做：缺失处理 → 去极值 → 行业内/全市场标准化（z-score 或分位）→ 方向对齐（越大越好）。

> 因子接口见 `src/alpharadar/factors/library.py`。

## 3. 规律挖掘 Pattern Mining（第 3 层）—— 系统大脑

目标：**从 15 年历史中，按市场状态分组，找出「未来会跑赢的股票」具备哪些因子组合。**

### 3.1 监督学习框架

把它建模成一个「横截面排序/分类」问题：

```
对每个调仓时点 t（如每月末）：
  X_t = 全市场股票在 t 时刻的因子值（横截面）
  s_t = t 时刻的市场状态标签（来自第 2 层）
  y_t = 各股票 t→t+H 的前瞻收益（H 默认一个季度），转为「是否跑赢中位数」

按状态 s 分组，在每组内学习：  f_s(因子) → 跑赢概率
```

- **标签 y**：用前瞻超额收益（相对行业或宽基），避免被 beta 主导。
- **分状态训练**：bull-growth 学一组权重，bear-value 学另一组——这就是「不同状态下的上涨共性」。
- **模型**：先用可解释模型（带正则的逻辑回归 / 单调约束的 GBDT / IC 加权），输出**因子权重**而非黑箱。
- **产物**：每个市场状态对应一个 `Pattern`（因子 → 权重 + 适用状态 + 样本内外表现）。

### 3.2 防过拟合（最重要）

15 年数据 + 多因子极易过拟合，必须严守：

1. **滚动/扩展窗样本外**：Walk-forward，只用过去训练、未来验证，绝不用全样本拟合再回测。
2. **point-in-time**：因子只用当时已公布数据（财务按 `ann_date`）。
3. **含退市股**：股票池纳入退市/ST，消除幸存者偏差。
4. **交易成本与容量**：扣除手续费、冲击成本，剔除不可成交（停牌/涨跌停）。
5. **稳健性**：看因子 IC 的稳定性与衰减，而非只看一次回测的收益曲线。
6. **少即是多**：因子数量克制，优先经济含义清晰的因子。

### 3.3 评估指标
- 因子层：IC / RankIC、IC_IR、分层单调性。
- 组合层：年化超额、信息比率 IR、胜率、最大回撤、换手率、不同状态下的稳定性。

## 4. 主线映射 Theme（第 4 层）

产业链是**人工知识 + 数据增强**的混合体：

- **人工骨架**：在 `config/themes/*.yaml` 里画出「主题 → 环节 → 瓶颈 → 关键变量 → 候选股」。
  例：AI → 算力 → 数据传输 → **光模块（瓶颈）** → 传输速率/产能/良率 → [候选股池]。
- **数据增强**：用行业景气因子给各环节打分，自动识别「当前最受益的瓶颈环节」，
  并用成分股数据补全/校验候选池。
- **触发条件**：每条主线可定义 `triggers`（如「市场状态=成长占优」且「行业景气>阈值」且「政策信号=支持」），
  满足才激活，避免在逆风状态下硬选。

## 5. 公司基本面打分 Fundamental（第 5 层）

对主线圈定的股票池，逐家按季度财务打分。强调**边际变化**与**兑现度**：

- 成长加速度（增速的二阶变化）比单期增速更重要。
- 产能/资本开支（capex）反映扩张意愿，对应「制造企业的能力」。
- 估值分位防止追在高位（同样基本面，分位低者优先）。
- 输出每家公司的**分项得分 + 总分**，供选股层加权。

## 6. 综合选股 Selection（第 6 层）

最终得分 = 按**当前市场状态**对各维度加权：

```
score(stock) =  w_prosperity(s) · 景气
              + w_growth(s)     · 成长
              + w_quality(s)    · 质量
              + w_momentum(s)   · 动量
              + w_valuation(s)  · 估值
              + w_theme(s)      · 主线契合度
```

权重 `w(s)` 由第 3 层规律挖掘按状态 s 给出（而非拍脑袋）。
取 Top 1~2，连同分项明细交给报告层解释。

## 7. 从「例子」到「方法」的对照

| 你的例子 | 对应方法 |
|----------|----------|
| 国家经济/政策情况 | 第 2 层 macro/liquidity 维度 + 主线 `policy_signals` |
| 人工智能行业爆发 | 第 4 层主题触发 + 景气因子 |
| 数据传输是核心、光模块是瓶颈 | 第 4 层产业链 YAML 的 bottleneck 标注 |
| 传输速率/制造能力 | 主线 `key_variables` + 行业景气因子 |
| 各季度指标分析 | 第 5 层 fundamental 打分 |
| 确认一两家公司买入 | 第 6 层 selection Top 1~2 + 第 8 层报告 |
